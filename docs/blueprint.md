# **App Name**: CogniPrep AI

## Core Features:

- User Authentication: Secure user registration and login functionality using JWT-based authentication.
- Resume Upload & Parsing: Allows users to upload their resume (PDF/DOC) and an AI tool parses it to extract key information like skills, experience, and projects for personalization.
- Job Role Selection: Users can select their target job role (e.g., 'Full Stack Developer') to customize interview question generation.
- AI Question Generator (Text Mode): An AI tool generates tailored HR, technical, and scenario-based interview questions in a text-based chat interface based on the user's resume and selected role.
- Text Interview Interface: A chat-based interface where users can type their answers to AI-generated interview questions.
- AI Feedback System: An AI tool evaluates user answers in real-time or post-session, providing feedback on answer quality, communication, and technical accuracy.
- Performance Dashboard (Basic): Displays basic interview session scores and identifies potential weak areas to track user improvement over time.

## Style Guidelines:

- Primary brand color: A deep, professional teal-blue (#0E7399) that conveys clarity and precision.
- Background color: A very light, cool-toned grey (#EBF3F5) providing a clean and focused canvas.
- Accent color: A vibrant, clear blue-purple (#6666E6) used for calls-to-action and key highlights, symbolizing insight and innovation.
- Headlines will use 'Space Grotesk' (sans-serif) for a modern, tech-forward, and assertive feel.
- Body text will use 'Inter' (sans-serif) for excellent readability, a neutral aesthetic, and broad usability across all text-heavy elements.
- Use minimalist, clear, and modern SVG icons that support the user's understanding without visual clutter.
- Implement a clean, content-focused layout with generous whitespace to promote concentration and clarity during interview preparation. Ensure mobile responsiveness across all key views.
- Subtle and functional animations, such as smooth transitions for content changes or a loading indicator during AI processing, to enhance perceived performance and user experience without distraction.
